#### 方差
##### 特性：
```
方差越大，说明随机变量的取值分布越不均匀，变化性越强；方差越小，说明随机变量的取值越趋近于均值，即期望值。

```

##### 概率密度和直方图

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.neighbors import KernelDensity

data_var_large = np.random.normal(loc=0, scale=10, size=1000)  # 方差大
data_var_small = np.random.normal(loc=0, scale=1, size=1000)   # 方差小


plt.figure(figsize=(10, 6))
plt.hist(data_var_large, bins=30, alpha=0.5, color='blue', label='Large Variance', density=True)
plt.hist(data_var_small, bins=30, alpha=0.5, color='red', label='Small Variance', density=True)

# 使用高斯核函数拟合
kde_large = KernelDensity(kernel='gaussian', bandwidth=1).fit(data_var_large.reshape(-1, 1))
kde_small = KernelDensity(kernel='gaussian', bandwidth=1).fit(data_var_small.reshape(-1, 1))

# 生成一组值用于绘制概率密度曲线 差不多3倍 最大scale
x_values = np.linspace(-30, 30, 1000)

# 计算概率密度
log_density_large = kde_large.score_samples(x_values.reshape(-1, 1))
density_large = np.exp(log_density_large)

log_density_small = kde_small.score_samples(x_values.reshape(-1, 1))
density_small = np.exp(log_density_small)

# 绘制概率密度曲线
plt.plot(x_values, density_large, color='blue', label='Large Variance (KDE)')
plt.plot(x_values, density_small, color='red', label='Small Variance (KDE)')

plt.xlabel('Value')
plt.ylabel('Probability Density')
plt.title('Histogram and Probability Density Comparison')
plt.legend()
plt.grid(True)
plt.show()

```
